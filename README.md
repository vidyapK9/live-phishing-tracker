# Live Phishing Campaign Tracker & Infrastructure Analysis

An OSINT-driven investigation of 45 active phishing campaigns sourced from public threat intelligence feeds (OpenPhish and URLhaus). All targets were safely triaged and analyzed out-of-band using urlscan.io, VirusTotal, and DNS telemetry without direct interaction.

---

## 🎯 Executive Summary & Objectives

- **Primary Goal:** Track active brand targeting, deceptive domain patterns, and infrastructure abuse across contemporary phishing kits.
- **Scope:** 45 unique active phishing URLs collected over a 48-hour window.
- **Safety Standard:** Zero direct browser contact. All scans executed via automated sandboxes and OSINT API telemetry. All Indicators of Compromise (IoCs) are defanged.
